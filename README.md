# 活版実験室

Next.js / Reactの画面とRust / WebAssemblyの印刷エンジン。ブラウザ内で画像から単色用の凸版を作り、インクを塗って紙へ転写します。

## 解像度

- シミュレーションの紙：**8192 × 8192 / 4096 × 4096**を選択できます（初期値8K）。インク転移、紙の接触、にじみ、飛沫、湿ったインクの移動、圧痕をこの格子で処理します。
- PNG保存：**4096 × 4096**。8Kでは格子の2 × 2点を、色へ変換した後で平均します。4Kでは対応する計算セルをそのまま保存します。プレビューを拡大して保存する処理ではありません。
- 画面プレビュー：640 × 640。版のプレビュー・手塗りの膜厚と顔料のフィールド：512 × 512。手塗りを8Kの版上で双線形補間します。
- 画像の輝度／選択したRGB成分：8K時6552 × 6552、4K時3272 × 3272。二値化／網点の凸部を8K紙の対応する位置で評価します。

紙は64 × 64のタイルに分割し、インクや圧痕が発生したタイルだけ確保します。紙の光学濃度は16ビット固定小数点で保存し、紙目を座標から生成します。密な全面印刷では紙の状態だけで8Kで約0.94 GB、4Kで約0.235 GB、画像入力・出力・ブラウザのキャンバスにも追加メモリが必要です。8K処理はWeb Worker上で行いますが、処理時間や必要メモリは画像と端末に依存します。

「計算解像度」を選び「選んだ解像度で新しく始める」を押すと、版・塗布インク・紙をリセットして開始します。`?resolution=4096`でも4Kで開始できます。印刷途中での自動切り替えはありません。

## ローカル起動

```cmd
pnpm install --frozen-lockfile
pnpm dev
```

コンパイル済みWASMとWorkerを同梱しています。Next.jsの依存関係はpnpm-lock.yamlに固定されています。

## Rustを変更する

rustupから最新のstableをインストールします。rust/rust-toolchain.tomlでもstableを選択しています。

```cmd
rustup update stable
rustup target add wasm32-unknown-unknown
pnpm build:wasm
pnpm test:wasm
pnpm dev
```

Windows上の標準MSVC構成で通常のcargo testを実行するには、Visual StudioのC++ビルドツールとWindows SDKが必要です。このエンジンのWASMだけをビルドし、Node.jsでWASMをテストする場合はそれらを必要としません。エンジンに外部クレートやC/C++ビルドスクリプトはありません。

```cmd
cargo test --manifest-path rust/Cargo.toml
pnpm exec eslint .
pnpm exec tsc --noEmit
pnpm build
```

## テスト

- rust/src/lib.rs：圧力ゼロ、塗布インクの減少、転移量、8K→4Kの平均化、乾燥・紙の交換を検査します。計算規則の単体テストは小さな格子で実行します。
- scripts/test-wasm.mjs：実際の8192格子のWASM、疎なタイル確保、4096出力、転移、乾燥、膜厚減少、厚塗り、Workerのメッセージ転送と進捗を検査します。全8K面を厚塗りする負荷テストではありません。
- GitHub Actions：Rustテスト、WASMビルド／テスト、ESLint、Next.jsビルドを行ってoutをPagesへ公開します。

## モデルの範囲

カラー画像は輝度またはRGB成分を単色用の網点・二値版に変換します。原画像の色を自動で多版印刷する機能はありません。塗った色は版の膜厚とともに保持され、印刷で減少します。

接触・分離・インク輸送は物理現象を参考にした簡略モデルです。色はRGBから計算した光学濃度の近似で、分光顔料モデルではありません。広がりと飛沫は再現可能な乱数で転移先を選びます。実測の粘度・圧力・紙物性による実機結果の予測には使えません。

参考文献：[Studies on Printing Ink Transfer (1986)](https://www.jstage.jst.go.jp/article/nig1958/24/1/24_1_41/_article/-char/en)


## 文献を踏まえた転移量の改訂

接触面積率、有限の紙側受容量、残余膜の分裂を分けて扱います。

- 1986年の転移実験（J-STAGE要旨確認）は、圧力・膜厚による被覆率の変化と、膜厚・速度による分裂率の変化を報告しています。
- 1991年の転移パラメータ推定研究（J-STAGE要旨確認）は、被覆面積も測定して係数を推定する必要性と、元の固定化関数の限界、Weibull型関数への改訂を述べています。
- 今回はWeibull型の被覆／受容曲線、有限の受容量、膜厚・速度による残余膜の分裂率を使う現象論的近似です。論文の実測係数の再現や1991年の式の忠実な実装ではありません。受容量の紙粗さ・粘度への対応も仮の係数です。転移量をゼロ以上・塗布量以下に制限します。
- 2020年の液橋論文（arXiv本文確認）は、PAA水溶液で濡れ性と粘弾性が分配を大きく変えることを示します。油性の活版インクに同じ数値を移せる根拠はありません。現行の剥離方向・飛沫は依然簡略表現で、この論文の流体計算を実装したものではありません。

次に改善すべき点は、紙表面の高さ場と圧縮による接触、表面インクと内部に浸透する溶媒／顔料の分離、剥離する液橋の粘弾性、顔料の分光的な重ね色です。とくに紙上の柄に合わせてランダム汚れを足すだけでは、これらを再現できません。実物の刷りで被覆率・濃度・輪郭の広がりを測って調整する必要があります。

追加文献：
- [A Modified Method for the Determination of the Ink Transfer Parameters by Non-linear Optimization (1991)](https://www.jstage.jst.go.jp/article/jtappij1955/45/7/45_7_809/_article/-char/en)
- [Viscoelastic Liquid Bridge Breakup and Liquid Transfer Between two Surfaces (2020)](https://arxiv.org/abs/2001.10209)


## 背景透過PNG

「PNGの紙を透過する」を有効にすると、4K RGBA PNGにインクの光学濃度だけを出力します。紙目・圧痕は出力せず、インクのないセルはalpha=0、薄いインク・にじみは半透明になります。8K→4Kは色をalphaで重み付けしてから平均し、縁に紙色が混ざるのを防ぎます。RGBAは白背景上でモデルのインク透過率を再現する近似であり、任意の背景上での実際の印刷色を保証するものではありません。現行モデルは吸収色のみで、白色顔料の隠蔽力は再現できません。
